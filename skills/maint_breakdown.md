**Last Updated:** 2025-04-02  
**Status:** Current

## P-Class Classification
| Priority | Response Time | Definition |
|----------|--------------|------------|
| P1 | 30 min on-site | Production stopped, safety risk |
| P2 | 2 hours | Production severely reduced |
| P3 | 8 hours | Production partially affected |
| P4 | Next scheduled | No immediate impact |

## Diagnostic Approach
1. Verify the fault — operator description + CMMS log
2. Visual inspection — look for obvious damage
3. Measured checks — amperage, temperature, vibration
4. Review recent history — same issue? PM on time?
5. Root cause — apply 5-Why or fishbone

## CMMS Work Order Requirements
- Failure code (from standard list)
- Description of fault
- Parts used with serial numbers
- Hours spent per technician
- Root cause before closure

## LOTO for Repairs
- Always raise PTW before internal inspection
- Personal lock + tag for each technician
- Verify zero energy state before starting
