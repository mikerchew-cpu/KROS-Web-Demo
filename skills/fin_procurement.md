# Procurement & Vendor Management

**Module:** Finance  
**Owner:** Finance Manager  
**Last Updated:** 2025-03-08  
**Status:** Current

## Authority Matrix
| Value | Required Approval |
|-------|------------------|
| < RM 5,000 | Department Head |
| RM 5,000 - RM 50,000 | GM / Mine Manager |
| > RM 50,000 | Board / Executive Committee |

## 3-Way Match Process
1. Purchase Order (raised by requestor)
2. Goods Receipt Note (receiving department)
3. Invoice (supplier)
- All 3 must match within 2% for payment processing
- Discrepancies referred to Finance Manager

## Approved Vendor List
- Vendors reviewed annually
- Selection criteria: price, quality, delivery, safety record
- Minimum 3 quotations for > RM 10,000

## Anti-Corruption Procedures
- Gifts policy: max RM 200 per occasion
- Declaration of interest register maintained
- Whistleblower hotline: Ext 1998
