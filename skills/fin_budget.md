# Mine Budgeting & Cost Coding

**Module:** Finance  
**Owner:** Finance Manager  
**Last Updated:** 2025-01-10  
**Status:** Current

## Cost Coding Structure
| Level | Code | Description |
|-------|------|-------------|
| 1 | 1000 | Mining Operations |
| 2 | 1100 | Drilling |
| 3 | 1110 | Drill consumables |
| 2 | 1200 | Blasting |
| 3 | 1210 | Explosives |
| 2 | 1300 | Load & Haul |
| 3 | 1310 | Loading |
| 3 | 1320 | Hauling |

## Unit Rate Method
- Budget built bottom-up using unit rates
- Rates reviewed annually with 5% escalation assumed
- Volume × rate = total cost per cost code

## Variance Thresholds
| Variance | Action |
|----------|--------|
| < 5% | Monitor |
| 5-10% | Explanation required from Department Head |
| 10-20% | Formal investigation |
| > 20% | Mine Manager review + corrective action plan |

## Monthly Review Cycle
1. Actuals posted by 5th
2. Variance report by 7th
3. Department review by 10th
4. Management review by 15th
