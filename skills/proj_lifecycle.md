# Project Lifecycle & Governance

**Module:** Projects  
**Owner:** General Manager / PMO  
**Last Updated:** 2025-02-28  
**Status:** Current

## 5-Phase Gate Model
| Phase | Gate | Key Deliverable |
|-------|------|----------------|
| 1. Initiation | Gate 0 | Project charter + budget estimate |
| 2. Planning | Gate 1 | Feasibility study + execution plan |
| 3. Execution | Gate 2 | Construction/implementation |
| 4. Monitoring | Gate 3 | Progress reports + change control |
| 5. Close-out | Gate 4 | Handover + lessons learned |

## PEP Requirements (Project Execution Plan)
- Scope statement, WBS, schedule, budget
- Risk register, quality plan, HSE plan
- Communication plan, stakeholder matrix
- Resource plan, procurement strategy

## Change Control
- Any change > 5% of budget requires Change Request
- Approved by Project Sponsor
- Impact assessed: cost, schedule, quality, HSE
- All changes logged in change register

## Project Archive
- Final documentation: as-built drawings, manuals, warranties
- Lessons learned register
- Close-out report with 12-month review trigger
