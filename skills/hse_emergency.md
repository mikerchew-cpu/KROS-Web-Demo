# Emergency Response Procedures

**Module:** Safety / HSE  
**Owner:** HSE Manager  
**Last Updated:** 2025-04-25  
**Status:** Current

## Emergency Contacts
- Emergency: 999
- On-site clinic: Ext 2000
- Mine Control: Ext 1999
- Nearest hospital: 30 min drive

## Injury Response
1. First aider assesses — do not move if spinal suspected
2. Call Mine Control with location and injury type
3. Ambulance dispatched from clinic
4. Incident area secured — no disturbance
5. Complete JKKP 6/7 as applicable

## Fire Response
1. RAISE alarm — shout + air horn + radio
2. EVACUATE to designated assembly point
3. ATTACK only if training + correct extinguisher + clear exit
4. DO NOT use water on electrical fires

## Slope Failure
1. Immediately evacuate area below failure
2. Geotechnical team inspects
3. Radar monitoring intensified
4. No re-entry without geotech clearance
