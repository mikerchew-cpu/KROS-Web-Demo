# Competency Framework & Assessment

**Module:** HRM  
**Owner:** HR Manager  
**Last Updated:** 2025-03-20  
**Status:** Current

## Competency Levels 0-4
| Level | Label | Definition |
|-------|-------|------------|
| 0 | Not Assessed | No evaluation completed |
| 1 | Aware | Can describe the process with guidance |
| 2 | Practitioner | Can perform independently with standard outputs |
| 3 | Proficient | Can train others and handle exceptions |
| 4 | Expert | Can design improvements and audit |

## Role Mapping
- Each role has 8-12 required competencies
- Minimum passing level specified per competency
- Assessment cycle: annual with 6-month review

## Critical Competencies (Zero Tolerance)
Items marked with 🔴 require Level 2 minimum to work independently:
- LOTO procedure (all trades)
- PTW authorisation (supervisors)
- Emergency response (all personnel)
- Confined space entry (relevant trades)
