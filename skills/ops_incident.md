# Incident Logging & Escalation

**Module:** Operations  
**Owner:** HSE Manager  
**Last Updated:** 2025-03-15  
**Status:** Current

## Incident Classification
- **Class 1:** Fatality or permanent disability — notify DOSH within 24 hours
- **Class 2:** Lost time injury (LTI) — notify Mine Manager immediately
- **Class 3:** Medical treatment case — HSE investigation within 48 hours
- **Class 4:** First aid only — log in CMMS

## Escalation Tree
1. First responder → secures area + provides first aid
2. Supervisor → logs incident + notifies HSE
3. HSE Manager → investigation lead
4. Mine Manager → notification authority for Class 1 & 2

## DOSH Notification
- Form JKKP 6 for dangerous occurrences
- Form JKKP 7 for accidents
- Submission via e-DOSH portal
